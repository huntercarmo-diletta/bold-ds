# RELEASE · **BREAKING** — todo atributo das peças web passa a ser texto, e o seu escape por fora morre
**de**: ds-diletta v3.0.0 · **para**: conta-bold-ds · **data**: 2026-09-29

## O que mudou
Valor de fora não vira mais marcação dentro do shadow: 33 nós com `onerror` e 47 disparos na
`web-v2.9.0`, zero na `web-v3.0.0` — detalhe no CHANGELOG, entrada [3.0.0].

## O que você faz

| se você | faça |
|---|---|
| escapa o valor antes de passar ao atributo (os onze `escapaHtml` do console) | apague o escape no mesmo commit do `ref:` |
| passava marcação de propósito num atributo | use o slot da peça, ou texto |
| não faz nenhum dos dois | nada |

Troque o `ref:` pra `v3.0.0` / `web-v3.0.0`. A lista dos onze está na nota de 29/09 do seu pedido do
escape.
